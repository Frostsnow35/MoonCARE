 # MoonCare 硬件技术实现文档

  ---

  ## 一、硬件架构总览

  MoonCare 硬件系统采用**"传感采集 + 状态计算 + 多模态反馈"**的架构，围绕耳挂式可穿戴设备构建。

  ┌─────────────────────────────────────────────────────────┐ │                      生理信号输入                      …
   │ │            (PPG心率 / 皮肤温度 / 运动姿态)                  │ │                          ↓                      …
        │ │              ┌─────────────────────┐                    │ │              │   主控芯片 ESP32-S3  │          …
          │ │              │  (数据处理 + 状态判断) │                    │ │              └─────────────────────┘      …
              │ │                          ↓                              │ │              ┌─────────────────────┐
               │ │              │     多模态反馈层      │                    │ │              │  (震动马达 + LED灯光)  …
                     │ │              └─────────────────────┘                    │ │                          ↓
                      │ │              ┌─────────────────────┐                    │ │              │      通信输出     …
   │                    │ │              │  (串口调试 / BLE传输) │                    │ │              └────────────────
  ─────┘                    │ └─────────────────────────────────────────────────────────┘


  **系统特点：**
  - 多传感器融合（PPG + 温度 + IMU）
  - 本地实时计算（无需依赖云端）
  - 多通道反馈（震动 + 灯光）
  - 支持串口与蓝牙数据输出

  ---

  ## 二、主控芯片 / 开发板

  ### 主控方案：ESP32-S3-N16R8 开发板

  | 参数 | 规格 |
  |:---|:---|
  | 主控芯片 | ESP32-S3 |
  | 内存 | 16MB Flash + 8MB PSRAM |
  | Wi-Fi | 2.4 GHz，支持 802.11 b/g/n |
  | 蓝牙 | Bluetooth 5 LE |
  | 工作电压 | 3.3V |
  | GPIO数量 | 丰富的可编程 GPIO |

  **选型原因：**
  - 集成 Wi-Fi 与 BLE（适合后续手机 APP 联动）
  - 运算能力足够处理实时信号（心率、HRV计算）
  - GPIO 丰富，适合多传感器接入
  - 支持 PWM（用于震动马达精细控制）
  - Arduino 生态成熟，开发效率高

  **当前使用能力：**
  - I2C 通信（连接 MAX30102、MPU6050、TMP117）
  - PWM 输出（控制马达强度，实现呼吸引导效果）
  - GPIO 控制（LED / 按钮）
  - 串口输出（调试与数据传输）
  - BLE 广播（无线数据传输）

  ## 三、传感器清单

  当前系统采用三类传感器，共用 I2C 总线：

  ### 1. 心率传感器：MAX30102（PPG）

  | 参数 | 规格 |
  |:---|:---|
  | 型号 | MAX30102（MH-ET LIVE 模块） |
  | I2C地址 | 0x57 |
  | 功能 | 光电容积脉搏波采集 |
  | 检测方式 | 红光(660nm) + 红外光(880nm) |

  **功能：**
  - 采集红光 / 红外光反射信号
  - 提取脉搏波形
  - 计算心率（BPM）
  - 支持 HRV（心率变异性）计算

  **输出数据：**
  - IR 信号（用于心率检测）
  - Red 信号（辅助血氧检测）

  **在系统中的作用：**
  - 计算实时心率
  - 判断佩戴状态（IR 信号强度检测）
  - 提取心跳间隔计算 HRV（情绪/压力指标）

  ---

  ### 2. 惯性传感器：MPU6050（IMU）

  | 参数 | 规格 |
  |:---|:---|
  | 型号 | MPU6050 |
  | I2C地址 | 0x68（ADO接GND） |
  | 功能 | 6轴运动检测 |
  | 加速度范围 | ±2g/±4g/±8g/±16g 可配置 |
  | 陀螺仪范围 | ±250°/s ~ ±2000°/s 可配置 |

  **功能：**
  - 三轴加速度（ax / ay / az）
  - 三轴角速度（gx / gy / gz）

  **在系统中的作用：**
  - 判断运动状态（HIGH / LOW）
  - 辅助判断信号可靠性（运动干扰过滤）
  - 动态基线算法：自适应识别静止/运动状态
  - HRV 计算时过滤运动伪影

  ---

  ### 3. 温度传感器：TMP117

  | 参数 | 规格 |
  |:---|:---|
  | 型号 | TMP117 |
  | I2C地址 | 0x48 |
  | 精度 | ±0.1℃（医疗级） |
  | 分辨率 | 0.0078125℃ |

  **功能：**
  - 高精度皮肤温度测量

  **输出数据：**
  - 实时温度（℃）

  **在系统中的作用：**
  - 判断是否贴近皮肤（温度阈值检测）
  - 识别"刚佩戴"状态（温度上升趋势）
  - 结合 PPG 提高佩戴识别准确性
  - 经期周期辅助参考（皮温趋势）

  ## 四、执行器 / 输出设备

  ### 1. 振动马达（核心反馈）

  | 参数 | 规格 |
  |:---|:---|
  | 类型 | 小型直流振动马达（ERM） |
  | 控制方式 | PWM 控制（ESP32 LEDC） |
  | PWM频率 | 1000 Hz |
  | PWM分辨率 | 8位（0-255） |

  **功能：**
  - 触觉反馈
  - 情绪引导（呼吸引导震动）

  **三种震动模式设计：**

  | 模式 | 适用场景 | 震动特征 |
  |:---|:---|:---|
  | **PRE_PERIOD** | 经期前提醒 | 双短震（210ms + 260ms，清晰提醒） |
  | **PMS_RISK** | PMS风险预警 | 双长震（320ms + 380ms，更强提醒） |
  | **BREATHING** | 呼吸疗愈引导 | 渐强-停顿-渐弱节律（模拟 Apple Watch 呼吸引导） |

  **呼吸引导震动细节：**

  吸气阶段：短脉冲逐渐增强 (duty: 70→195) 顶点停顿：轻停顿 380ms 呼气阶段：短脉冲逐渐减弱 (duty: 170→45) 底部休息：停顿
  620ms 循环：3个呼吸周期


  ---

  ### 2. LED 指示灯（状态可视化）

  | 参数 | 规格 |
  |:---|:---|
  | 类型 | 3颗独立 LED（红/黄/绿） |
  | 限流电阻 | 100Ω（每颗LED串联） |
  | 控制方式 | GPIO 数字输出 |

  **引脚分配：**
  | LED | GPIO引脚 |
  |:---|:---|
  | 红灯 | GPIO6 |
  | 黄灯 | GPIO7 |
  | 绿灯 | GPIO8 |

  **模式指示逻辑：**

  | 当前模式 | 待机状态 | 执行中（慢闪） |
  |:---|:---|:---|
  | PRE_PERIOD | 黄灯常亮 | 黄灯慢闪 |
  | PMS_RISK | 红灯常亮 | 红灯慢闪 |
  | BREATHING | 绿灯常亮 | 绿灯慢闪 |

  **异常状态：**
  - 低置信度 / 传感器异常：红灯快闪（180ms周期）

  ---

  ### 3. 按钮输入（交互控制）

  | 按键 | GPIO引脚 | 功能 |
  |:---|:---|:---|
  | 白键 | GPIO11 | 短按：切换模式（PRE_PERIOD → PMS_RISK → BREATHING） |
  | 白键 | GPIO11 | 长按（>1s）：切换手动/自动模式 |
  | 绿键 | GPIO12 | 短按：触发当前模式震动 |
  | 绿键 | GPIO12 | 长按（>1s）：停止震动 |

  **消抖处理：** 40ms 软件消抖

  六、电路连接说明（核心接线）

  GPIO5 (SDA) ─────┬─────► MPU6050 SDA
                   ├─────► MAX30102 SDA
                   └─────► TMP117 SDA

  3V3 ─────────────┬─────► 所有传感器 VCC/VIN
                   │
  GND ─────────────┴─────► 所有传感器 GND

  八、系统核心算法逻辑

  1. 心率计算流程

  IR信号采集 → 平滑滤波 → 峰值检测 → 计算IBI → 换算BPM
                  ↓
            运动干扰过滤（MPU6050）

  2. 运动状态判断（动态基线算法）

  // 不再使用绝对阈值，而是自适应基线
  motionBaseline = 慢速跟踪基线（重力方向）
  motionDeviation = 快速偏差平滑
  HIGH/LOW 切换使用滞回阈值，避免抖动

  3. 佩戴判断（多传感器融合）

  PPG信号质量（IR强度 > 50000）
  + 温度绝对值（皮肤温度范围）
  + 温度变化趋势（刚戴上时温度上升）
  = 综合置信度 HIGH/LOW

  十、注意事项

  1. 供电统一使用 3.3V，不要混用 5V
  2. 马达必须通过三极管/MOS驱动，不能直接接 GPIO
  3. PPG 传感器需要稳定接触皮肤，耳饰形态建议采用耳夹设计
  4. I2C 总线速度建议 100kHz，调试稳定后可尝试 400kHz
  5. 所有 LED 必须串联限流电阻（100Ω或330Ω）
