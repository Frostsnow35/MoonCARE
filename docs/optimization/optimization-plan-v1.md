
# MoonCARE 聊天Agent优化方案 v1.0

## 1. 问题概述

当前聊天Agent存在两个主要问题：

### 1.1 情绪陪伴引导不足
- 缺乏主动引导用户表达的温柔提问
- 行动建议不够丰富和有针对性
- 未有效结合站内功能和外部建议

### 1.2 知识问答质量问题（综合模式）
- 对知识类问题识别不够准确
- 回答泛泛而谈，缺乏针对性
- 有时会出现奇怪或不符合逻辑的建议

## 3. 优化方案

### 3.1 优化一：改进情绪陪伴引导与行动建议

#### 目标
- 增加温柔、有针对性的提问
- 提供丰富的站内+外部结合的行动建议
- 避免说教式科普，专注情绪陪伴

#### 具体改进

##### 3.1.1 优化 `support_prompt.txt`
在 `default_chat_prompt.txt` 和 `support_prompt.txt` 中新增以下要求：

| 编号 | 要求说明 |
|------|----------|
| OP-101 | **增加引导性提问**：每轮回复最后可以包含1个温柔的开放式问题，引导用户表达更多 |
| OP-102 | **结合站内功能**：自然推荐合适的站内功能（如"你可以试试呼吸练习"），不要太生硬 |
| OP-103 | **外部建议**：同时给出1-2个简单、可立即执行的外部建议（如"去窗边站一会儿"） |
| OP-104 | **避免说教**：用户情绪不好时，先共情陪伴，不要先讲生理原因或科普知识 |

##### 3.1.2 增强 `_generate_action_suggestions` 函数
在 `agent_service.py` 中丰富行动建议库：

- 扩大关键词覆盖范围
- 增加更精细的情绪分类
- 每类建议提供站内功能 + 外部小行动组合
- 支持最多3个建议，优先推荐最相关的

### 3.2 优化二：改进知识问答准确性与质量

#### 目标
- 提高知识类问题识别准确率
- 优化知识库检索与回答质量
- 避免泛泛而谈和诡异建议

#### 具体改进

##### 3.2.1 优化知识路由识别 (`_looks_like_knowledge_question`)

当前问题：识别规则过于严格或不够准确

改进策略：

| 维度 | 当前问题 | 改进方案 |
|------|----------|----------|
| 疑问词 | 仅检查几个词 | 扩展疑问词库（包括"怎么办"、"如何"、"为什么会"、"怎么缓解"等） |
| 主题词 | 仅检查少量词 | 扩展主题词库（包括"经前"、"经期"、"情绪"、"烦躁"、"失眠"等） |
| 组合逻辑 | 需同时满足疑问词+主题词 | 更灵活：有疑问词且有情绪/健康主题词 → 知识路由；或直接有明确"如何缓解"句式 |

新增识别规则：
```
识别条件（满足任一即可）：
1. 有疑问词 + 有健康/情绪/经前主题词
2. 有"怎么办"、"如何缓解"、"怎么改善"、"有没有办法"等特定短语
3. 明确问"是什么"、"为什么"的健康/情绪问题
```

##### 3.2.2 增强知识库检索 (`KnowledgeAgent`)

- 优化向量检索与关键词检索的权重
- 增加检索结果重排序逻辑
- 增强低置信度时的fallback逻辑

##### 3.2.3 优化知识回答提示词 (`knowledge_prompt.txt`)

新增要求：
- 基于检索到的参考资料回答，不要凭空生成
- 用通俗易懂的语言，避免太学术
- 保持"仅供参考"、"不做诊断"的原则
- 回答要具体，避免空泛

## 4. 实现任务分解

### 4.1 优先级（P0 - P1 - P2）

| 优先级 | 任务 | 描述 |
|--------|------|------|
| P0 | 优化知识路由识别 | 提高知识类问题识别准确率 |
| P0 | 优化知识Agent提示词与检索 | 提升知识回答质量 |
| P0 | 优化支持Agent提示词 | 增强引导性提问与行动建议 |
| P0 | 增强行动建议生成 | 丰富站内+外部建议组合 |
| P1 | 增加知识Agent单元测试 | 验证路由识别与回答质量 |
| P1 | 集成测试与验收 | 整体效果验收 |
| P2 | 优化知识库内容 | 补充更多实用知识条目 |

### 4.2 详细任务清单

#### Task-01: 优化知识路由识别 (`router.py`)
- 扩展疑问词库
- 扩展健康/情绪主题词库
- 优化识别逻辑，更灵活地判断知识类问题
- 增加路由结果日志，便于调试

#### Task-02: 增强知识Agent (`knowledge_agent.py` + prompts)
- 优化 `knowledge_prompt.txt`，增加具体回答要求
- 优化检索结果重排序
- 增强低置信度fallback处理
- 确保基于检索内容回答，避免凭空生成

#### Task-03: 优化支持Agent提示词
- 增强 `support_prompt.txt` 和 `default_chat_prompt.txt`
- 增加引导性提问要求
- 增加站内功能推荐要求
- 增加外部小建议要求
- 明确情绪不好时避免说教

#### Task-04: 增强行动建议生成 (`agent_service.py`)
- 丰富 `_generate_action_suggestions` 函数
- 增加更多情绪场景的建议
- 每个建议包含：站内功能 + 外部小行动
- 优化建议优先级逻辑

#### Task-05: 增加测试用例
- 知识路由识别测试
- 知识Agent回答质量测试
- 行动建议生成测试
- 端到端对话测试（关键场景）

## 5. 验收标准

### 5.1 情绪陪伴验收标准

| 场景 | 验收点 |
|------|--------|
| 用户表达"我好烦躁" | 1. 先共情 2. 推荐听音乐 3. 建议"去窗边呼吸点新鲜空气" 4. 温柔提问 |
| 用户表达"好焦虑" | 1. 先共情 2. 推荐呼吸练习 3. 建议"试试慢慢喝杯温水" 4. 温柔提问 |
| 用户表达"好难过" | 1. 先共情 2. 推荐写日记 3. 建议"抱抱自己" 4. 温柔提问 |

### 5.2 知识问答验收标准

| 场景 | 验收点 |
|------|--------|
| 用户问"为什么会经前烦躁" | 1. 准确路由到知识Agent 2. 基于知识库回答 3. 通俗易懂 4. 仅供参考 |
| 用户问"怎么缓解失眠" | 1. 准确路由到知识Agent 2. 给出具体建议 3. 仅供参考 |
| 用户问"这正常吗" | 1. 准确路由到知识Agent（结合语境）2. 合适回答 3. 仅供参考 |

### 5.3 综合模式验收标准

| 场景 | 验收点 |
|------|--------|
| 用户先表达情绪，又问知识问题 | 1. 灵活切换 2. 情绪部分陪伴 3. 知识部分准确回答 |
| 用户消息混合情绪与问题 | 1. 准确识别主要意图 2. 合适路由 3. 高质量回复 |

## 6. 风险与注意事项

| 风险 | 预防措施 |
|------|----------|
| 路由识别过度（把情绪问题误判为知识问题） | 保持危机优先，设置阈值，增加测试用例 |
| 行动建议太多太杂 | 最多3个，按优先级排序 |
| 引导性提问太生硬 | 在提示词中强调自然、温柔 |
| 推荐功能时破坏聊天体验 | 在提示词中强调自然结合，不生硬 |
